# Brouillons de questions (non vérifiées)

Questions rédigées automatiquement puis interrompues avant la relecture contre les règlements.
Elles ne sont **pas** compilées dans l’application. Pour en intégrer un fichier : le relire,
le contrôler avec `python scripts/check_questions.py <fichier>`, le déplacer dans
`content/questions/` puis lancer `python scripts/build_site.py`.
